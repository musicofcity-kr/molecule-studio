# 자료 조사와 수치 분석의 완료 근거

출처·기준 시점·단위·입력 데이터와 확인 가능한 결론을 연결합니다. 동적 정보는 확인 시점을 적고 실제 열람한 1차 자료를 우선합니다. 계산은 원자료로 재현하고 독립적인 계산 경로로 대조합니다.

입력·분석 코드·버전 명세를 source_paths에 포함하고 결과 파일을 deliverables로 지정합니다. 데이터가 부족하면 확인되지 않은 수치 대신 한계를 기록합니다. 추정·가설·AI의 설계 선택은 사실과 구분합니다.

과학적 정확성은 출처·실험·계산 검증으로 판단합니다. 단위검사 통과율로 화학적 정확도나 교육 효과를 대신 평가하지 않습니다. 민감한 학생 자료를 모델·외부 서비스로 전송하는 권한은 호스트와 사용자의 실제 지시를 따릅니다. 이 폴더에 저장했다는 이유만으로 클라우드 모델 처리가 로컬 연산이 되지는 않습니다.

examples/analysis는 합성 CSV 자료의 평균·개수·단위를 대조하는 동작 예시입니다. 실험에서 얻은 측정 데이터가 아닙니다.
