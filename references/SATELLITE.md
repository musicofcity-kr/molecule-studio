# 필요할 때 사용하는 서브에이전트

상시 노드 감시와 역할별 에이전트 호출은 기본 경로에 없습니다. 호스트와 사용자가 위임을 허용하며, 독립적인 작업이나 별도 검토가 실제로 도움이 될 때 사용합니다.

위임할 때는 목적, 필요한 입력 파일, 수정 가능한 경로, 반환 산출물과 완료 조건만 전달합니다. 전체 대화와 모든 문서를 일괄 복사하지 않습니다. 작업자는 겹치지 않는 범위를 맡고, 주 에이전트가 통합 결과를 확인합니다.

감시 역할은 소스 수정 권한 없이 실제 오류·정체·완료 근거의 문제를 보고하도록 둘 수 있습니다. 호출 여부와 모델은 호스트의 사용 가능한 기능과 작업 예산으로 결정합니다. 이 템플릿은 감시 에이전트를 생성하거나 비용을 측정하지 않습니다.

개별 에이전트가 같은 변경을 반복 검증하게 하기보다, 이미 실행한 검증의 대상·결과·현재성 정보를 공유합니다. 독립적 재검토가 요구되는 기준은 그 요구를 계약에 명시합니다.
