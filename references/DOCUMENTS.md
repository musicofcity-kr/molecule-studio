# 문서 작업의 완료 근거

요청 내용·대상 독자·분량·출력 형식을 완료 기준으로 만듭니다. 형식·글자 수·필수 항목은 실제 명령으로 검사할 수 있습니다. 내용의 연결·근거 유지·의미 왜곡은 열람 또는 비교 검토로 확인합니다.

DOCX·PDF·슬라이드는 최종 파일을 실제 열거나 렌더링해 잘림·겹침·폰트·표를 확인한 근거를 남깁니다. 마크다운 파일의 존재만으로 다른 형식까지 정상이라고 보고하지 않습니다.

생기부·평가 문서는 사용자가 준 관찰 근거에서 벗어난 사실을 추가하지 않습니다. 교사의 최종 판단이 완료 범위에 포함되면 human 검토 조건을 명시합니다. 단순 초안 작성과 실제 학생 평가의 완료 범위를 구분합니다.

examples/document는 마크다운 교정과 실제 텍스트 비교를 보여줍니다. 문서 전문 도구의 사용 지침은 해당 형식을 작업할 때만 읽습니다.
