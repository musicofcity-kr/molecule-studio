# 분자 모델링 비교시험 요청 예시

ai가 자의적으로 판단하여 결정한 대답:

같은 모델·입력·환경·사용 가능한 도구로 v3.1.1과 v4.0.0을 각각 새 폴더에서 비교합니다. 아래는 도메인별 완료 조건의 설계 예시이며 OpenAI가 지정한 벤치마크가 아닙니다.

교육용 분자 구조 모델링 프로그램을 제작해 주세요. 학습자가 분자를 입력·선택하고 3D 구조를 회전·확대해 원자와 결합을 확인할 수 있어야 합니다. 좌표 생성과 렌더링을 구분하고, 실제 지원 범위와 한계를 설명해 주세요. 요청한 기능을 구현한 뒤 실행·주요 조작·오류 처리를 확인하고 발견된 문제를 수정해 주세요.

완료 기준에는 설치 및 실행, 대표 입력과 잘못된 입력, 계산 라이브러리의 실제 좌표 생성, 구조 데이터와 화면 표시의 일치, 확대·회전·라벨 가독성, 결과 저장 후 재열기, 계산 방법·단위·한계의 설명을 포함하세요. 구체적인 분자 목록과 허용 오차는 사용 목적과 확인된 기준 자료에 맞춰 설정하고 근거를 기록하세요. 같은 모양처럼 보이는 것만으로 화학적 정확성을 확정하지 마세요.

소스·의존성 명세·기능 검사·필요한 화면 검토를 완료 계약에 연결하세요. AI에게 전달되는 내부 검증 절차를 학생의 주 화면에 일괄 표시하지 마세요.

측정할 항목: 요구 충족 여부, 설치·기능 결함 수, 사용자가 직접 확인한 가독성·조작 성공, 실제 경과 시간, 승인 요청 횟수, 호스트가 제공하는 토큰 사용량. 확인할 수 없는 값은 미측정으로 적으세요. 같은 과제를 반복해 변동을 확인하기 전에는 성능 우위를 확정하지 마세요.
