# 분자 스튜디오 사용법

1. 왼쪽에서 물·에탄올 등 예제를 고르거나 SMILES를 입력합니다. MOL 파일도 가져올 수 있습니다.
2. 직접 그리려면 편집기의 원소를 선택하고 빈 공간에 원자를 놓습니다. C·H·N·O·B·Si·P·S·F·Cl·Br·I의 12개 원소를 선택할 수 있습니다. 결합 도구와 차수를 선택한 뒤 연결할 두 원자를 누르고 **3D 만들기**를 누릅니다. 수소를 직접 그릴 수도 있고, 생략한 수소는 계산 시 자동으로 추가됩니다.
3. 3D 화면을 드래그해 회전하고 휠로 확대합니다. **원자 라벨** 체크박스로 구조 위의 식별 ID·원소 기호를 표시하거나 숨깁니다. **H 표시**는 수소 원자 자체를 켜고 끕니다. 라벨을 숨겨도 **거리**에서 두 원자를, **각도**에서 세 원자를 선택할 수 있습니다. 각도는 두 번째 원자가 꼭짓점입니다. 원자 목록으로도 선택할 수 있습니다.
4. **원자 보기**에서 중심 원자를 고르면 VSEPR 정보를 확인합니다. **오비탈**은 선택한 원자의 혼성 오비탈을 설명하는 개념 표시입니다.
5. 분광 탭에서 IR·1H NMR·13C NMR·UV-Vis 학습용 피크와 범위를 확인합니다. 규칙이 없는 구조는 지원하지 않는다고 안내합니다.
6. 측정값을 노트에 추가하고 관찰을 적은 뒤 컬렉션에 저장합니다. 컬렉션은 현재 브라우저의 로컬 저장소에 보관되며 다른 기기로 자동 동기화되지 않습니다.
7. **학습 카드**를 누르면 현재 구조와 정보를 PNG로 내려받습니다. 브라우저 데이터 삭제 전 필요한 기록을 이미지로 저장하세요.

## 계산과 데이터

구조 입력은 RDKit 계산 함수로 전송됩니다. API 키나 회원가입 없이 이용하며 앱은 노트·컬렉션을 서버에 저장하지 않습니다. 계산한 단일 배좌의 거리·각도는 실험값과 다를 수 있습니다. 스펙트럼은 교육용 규칙 기반 참고이며 정량 농도·정확한 흡수 세기·NMR 다중선·용매 효과를 예측하지 않습니다. 오비탈 개념도는 전자밀도나 HOMO/LUMO 계산 결과가 아닙니다.

자세한 지원 범위와 근거는 [SCIENCE.md](SCIENCE.md)를 참고하세요.

## 로컬 실행

Node.js 22.12 이상과 Python 3.13을 준비합니다.

```powershell
npm ci
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe api/molecule.py
```

다른 터미널에서 `npm run dev` 후 `http://127.0.0.1:5173`을 엽니다. `npm run build`는 배포용 정적 화면을 생성합니다. 서버 함수는 Vercel에서 별도로 실행됩니다.

## 오류가 날 때

- 잘못된 결합 수·SMILES: 원소와 결합 차수를 확인합니다.
- 계산 시간 초과·너무 큰 분자: 더 작은 단일 분자로 시도합니다.
- 3D 표시 불가: WebGL을 지원하는 최신 브라우저에서 하드웨어 가속을 확인합니다.
- 저장 공간 부족: 불필요한 컬렉션을 삭제하거나 PNG를 먼저 저장합니다.
