## 통합 보완

- 컬렉션 불러오기는 클릭한 저장본의 노트와 측정 기록을 정확히 복원합니다.
- 새 3D 계산에서는 이전 좌표에 속한 측정 기록을 초기화합니다. 노트 초안과 측정 데이터를 혼동하지 않습니다.
- 구조 변경 여부는 원자·전하·결합으로 비교합니다. 2D 배치 위치만 이동하면 현재 분자 저장을 막지 않습니다.
- 분석 중 2D 편집을 잠그고 완료 뒤 잠금 안내를 제거합니다. 빈 보드 안내 문구 위에서도 원자를 배치할 수 있습니다.
- 기존 API·과학 계산·교육용 한계 표현을 유지합니다.

## 검증

로컬 실행 결과는 다음과 같습니다. 최초 실패 및 검사 보완 기록은 보존했습니다.

- 생산 빌드: 교차 검토 수정 반영 후 통과. 기존 Three.js 청크 크기 경고는 남으며 실행 실패가 아닙니다.
- 신규 Chrome 회귀: 편집기 8/8, 저장·노트·키보드 4/4, 3D·PNG 4/4, 합계 16/16 통과. scripts/usability-check.mjs로 세 하위 검사를 실행합니다.
- 기존 전체 브라우저 검사: Edge/Playwright 23/23 통과, 페이지 오류 0개. 데스크톱·390px 모바일·실제 API·저장·PNG 포함.
- 화학 검사: 19/19 통과. 배포 번들 제외/보존 경로 검사도 통과.
- 실제 PNG: 메인과 Terra가 0·O / 1·H / 2·H 라벨의 존재를 육안 확인했습니다. 모바일 기본 화면의 도움말·편집기·노트·저장 버튼은 심각한 겹침/잘림 없이 표시됩니다.
- 최종 로컬 기록: local-verified/sketcher, local-verified/viewer, local-workflow-final, local-existing-verified. 아래 증거 루트 기준입니다.
- 원본 실사용 증거: 로컬 docs/audits/chrome-20260915/ 보존.
- 이번 실행 증거: evidence/usability-fixes-20260915/.

### 최초 실패와 보완

1. 생산 빌드가 진행되는 중 미리보기 탐색을 시도하여 HTTP 탐색 실패. 빌드 완료 후 격리 Chrome에서 화면·요소·오류 없음 확인.
2. 새 ‘입력한 SMILES 분석하기’ 복구 버튼 때문에 기존 부분 이름 선택자가 두 버튼을 매칭했습니다. 정확한 이름 매칭으로 기존/신규 회귀 스크립트를 보완했습니다.
3. 저장 경고 회귀가 좁은 보드 밖의 고정 좌표를 클릭했습니다. 실제 보드 크기로 좌표를 계산하도록 고친 뒤 해당 검사 4개를 재실행해 통과했습니다.

위 2·3은 검사 코드의 실패입니다. 제품 수정 전 결함 증거는 원본 Chrome 보고서에 별도로 남아 있습니다.

## 작업 및 검토 역할

Astra 메인이 범위·통합·최종 실행·배포 검증을 담당하고, 실제 Sol/Terra/Luna 모델의 서브에이전트가 독립 파일을 구현했습니다. Sol은 Terra의 편집기를, Terra는 Sol의 저장·노트 흐름을 읽기 전용 교차 검토했습니다. 통합 검토에서 발견한 잠금 문구 잔류, 저장본보다 초안 우선, 검사 완료 시점 오류를 수정했습니다.

## 한계

- 노트 초안은 현재 앱 세션 안에서 보존합니다. 새로고침 이후의 장기 보관에는 컬렉션 저장을 사용합니다.
- 지연 상태 검사는 실제 API 요청에 의도적인 테스트 지연을 추가합니다. 서비스 지연이나 성능을 측정한 결과가 아닙니다.
- 모든 기기·터치 제스처·분자 배치 및 접근성 전 항목을 검증했다는 의미는 아닙니다.
